## やったこと

単一の HTML に CSS と素の JavaScript が入っている。依存パッケージは無い。`<base target="_top">` があり、同じファイルを Google Apps Script の画面と、GitHub Pages の静的ページの両方に使う形になっている。

読み込みは `fetchEvents` の2経路。

- `google.script.run` があるとき: `acEvents()` の戻り値を使う。`today` はサーバの値のまま。
- それ以外: `events.json?t=` に現在時刻を付けて取得し、キャッシュを避ける。そのあと `today` を、閲覧時刻に9時間足した UTC 日付（日本時間の暦日）で上書きする。ファイル内の `today` は静的公開では使わない。

失敗したらグリッドに「読み込めませんでした」を出す。成功後は 30 分ごとに再取得する。再取得の失敗では、引数 `quiet` により今のグリッドを消さない。

状態 `st` は `data`, `ym`（表示月）, `sel`（選択日）, `off`（隠すジャンル）, `area`, `pref`, `kind`, `q`。初回描画で `ym` と `sel` を `today` にする。種類の `<select>` は `kinds` のキーから一度だけ足す。

エリアは HTML 内の固定表。全国、北海道・東北、関東、中部・東海、関西、中国・四国、九州・沖縄。所属判定は都道府県名を連結した文字列の `indexOf`。初期値は `localStorage` の `ac:area`。未保存または未知の id なら `kanto`。保存に失敗しても動く。都道府県の選択肢は、今のエリアに入るイベントに現れる県だけを、北から南の連結文字列上の位置で並べる。エリアを変えて今の県が消えたら選択をクリアする。

絞り込み `shown` は、隠したジャンル、エリア、都道府県、種類、検索（題名・会場・都道府県・DJ・handle の部分一致、大小無視）をすべて満たす行。チップの件数はこれとは別で、終了日（空なら開始日）が `today` 以降の行を、エリア（ジャンルチップはエリアとジャンル）だけで数える。検索、種類、都道府県、ジャンルを隠したことでは件数は減らない。

月グリッドは日曜始まりの最大6週。日付の加減は `Date.UTC` と `toISOString` の日付部分だけで、ローカルタイムゾーンを混ぜない。6週目がすべて翌月ならその週を出さない。各日は `date <= その日 <= (end || date)` の行を、時刻の空を `99` として昇順にし、最大4件を色付きの帯で出す。残りは「ほか N 件」。帯のクラス名は `genre` のキーで、色は CSS 変数 `--anison` / `--vocaloid` / `--vtuber`。

右側は選択日の一覧と、今日から14日以内の最大60件。行にフライヤーがあればサムネイル。画像 URL が `https://pbs.twimg.com/media/` のときはクエリを外し、一覧は `?name=small`、シートは `?name=medium` を付ける。ホバーできる端末では、帯と行の `data-f` で追従プレビューを出す。`(hover: none)` ではプレビューを出さない。日の「フライヤー一覧」とサムネイルは全画面シートを開く。シートは閉じるボタン、背景クリック、Escape で閉じ、背景スクロールを止める。

日をクリックするとその日を選択し、月が違えば表示月も移す。タッチ端末でその日に行があればシートを開く。幅 860px 以下の非タッチでは、右ペインへ `scrollIntoView` する。ジャンルのチップは `st.off` を反転するだけ。

フッターは `runNote(status)` に「最終更新: last」と版 `v` を続ける。`step` が `done` でなければ、抽出なら `i / posts`、検索なら `g / 3` を出す。`trigger` が `ok` なのに `tick` が無いときは、エディタで `acTick` を実行して許可する、という文を出す。初版のデータは `step: extract` の途中なので、公開ページには収集中の文が出る。

## うまくいった・失敗したこと

うまくいっている点は、日付計算を UTC に固定していること、文字列を `esc` してから HTML に入れていること、静的ページと Apps Script を同じ描画に流していること、再取得の失敗で画面を消さないこと、ホバーできない端末で追従プレビューを出さないこと。`end` が空でも単日として通る。

弱い点は、初版に `<title>` と viewport が無く、狭い画面ではイベント名が棒になること。タッチでは日を押すとシートが即開くので、右ペインの一覧を見る操作とぶつかる。フッターが収集の途中状態と、編集者向けの許可手順を公開ページに出す。初期エリアが関東なので、都道府県が空の行は開いた直後には出ない。チップの件数は検索条件を反映しない。

## 次から気をつけること（ルール化候補）

- 画面を変えるときは `<title>` と viewport をセットで見る。初版には両方無い。
- 日付の加減は `shift` / `dow` の UTC 方式を崩さない。`new Date("YYYY-MM-DD")` のローカル解釈を混ぜない。
- タッチでシートを開く経路を消すときは、フライヤーへたどり着く別のボタンが残っているかをノートに書く。この経路は次の画面コミットで削除される。
- 公開フッターに、エディタ操作や実行途中の `step` を出す条件を見直す候補。データ側が `extract` のまま commit される。
- ログのために `index.html` を整形し直したり、挙動を変えたりしない。
