## やったこと

フィルタと月送りのあいだに `<section id="week">` を足している。`draw` がグリッドの直後に `drawWeek(list)` を呼ぶ。`list` は `shown()` の結果なので、エリア、ジャンル、都道府県、種類、検索が帯にも効く。表示月には効かない。月を送っても帯の中身は「今日」基準のままである。

対象は、フライヤーがあり、終了日（空なら開始日）が今日以降で、開始日が今日+6日以内の行。今日は静的ページでは閲覧者の日本時間。`end` が全件空なので、開始日が昨日以前の行は帯に入らない。期間イベントをまたぐ表示は、データが `end` を埋めるまで動かない。並びは、開始日が今日より前なら今日に寄せた日付、次に時刻。件数が 0 ならセクションを空にする。

カードは幅 150px（640px 以下は 118px）、画像高さ 200px（狭い画面は 158px）。ジャンル名を左上の帯に出し、その下に日付と時刻、題名。`url` があればカード全体がその出典へのリンク。画像は一覧と同じ `small` 変換。見出しは「今週のイベント」と、今日〜6日後の日付、件数。

カード列の scrollWidth が枠より 8px を超えて広ければ、同じカードをもう一周分足して `data-loop` を付ける。複製側のリンクは `aria-hidden="true"` と `tabindex="-1"`。幅は固定なので、画像の読み込みを待たずにループ判定できる。

自動スクロールは `requestAnimationFrame` が1本。速度は秒あたり 28px。経過が 100ms を超えたフレームは 100ms として扱う。位置が全幅の半分を超えたら半分戻す。ホバー中は止め、離れたら今の scrollLeft から再開する。タッチ開始で止め、終了から 2.5 秒後に再開する。`document.hidden` のあいだは進めない。`prefers-reduced-motion: reduce` のときはループを開始しない。横スクロール自体は残る。`WEEK.raf` が既にあれば次の `drawWeek` では新しいループを足さない。位置 `WEEK.x` は描画のたびに 0 に戻す。

検索の `input` でも `draw` が走るので、1文字ごとに帯のスクロール位置が先頭に戻る。

## うまくいった・失敗したこと

今週のフライヤーが、月グリッドの上でフィルタと連動する。件数表示は複製前の配列長なので、ループ用のコピーを二重に数えない。モーションを減らす設定と、ホバーやタッチでの停止がある。ループを描画のたびに増やさないガードがある。ここを外すと速度が倍々になる。

弱い点は、検索のたびに帯が先頭に戻ること。`end` が空のデータでは、昨日から続いているイベントは今週の帯に出ない（月グリッドの「今日」のマスには、開始日が今日の行しか乗らない点は元から同じ）。収集途中のフッターは、このコミットでもそのままである。

`drawWeek` は `#week` を毎回作り直す。タッチのリスナーは新しい要素に付くので、古い要素と一緒に捨てられる。同じ要素へ重ねてはいない。
